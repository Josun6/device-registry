# 获取支持 / Support

Device Registry 由 **sunly56** 维护。请通过 GitHub 仓库的 **Issues** 提交使用问题、错误反馈和功能建议。无需公开个人邮箱。

提交问题时，请注明软件版本、Windows/Python 版本、复现步骤，以及预期与实际结果。截图和日志中请遮挡公司名称、设备编码、采购单据及其他敏感信息。

涉及安全漏洞时，优先使用 GitHub 的 **Private vulnerability reporting**（仓库维护者需在安全设置中启用）；请勿在公开 Issue 中披露漏洞利用细节。

---

For help, bug reports, and feature requests, please use **GitHub Issues**. Maintained by **sunly56**. No personal email address is published.

Include the app version, operating system, reproduction steps, and expected/actual behavior. Remove sensitive asset data from screenshots and logs. For security vulnerabilities, use GitHub Private vulnerability reporting if enabled.
