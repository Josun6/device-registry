## 数据安全

- [ ] 确认仓库没有真实 `devices.db`、`.db.bak`、`images/`、`attachments/`、CSV/XLSX 或备份 ZIP。
- [ ] 用 `git status`、`git diff --cached --name-only` 核对提交文件。
- [ ] 旧数据库先整套备份，在**副本**上进行升级和恢复测试。
- [ ] 确认本地编辑密码不等于数据库加密，向用户明确说明。

## 功能验收

- [ ] 资产清单固定为指定 14 列，顺序与 README 一致，不存在字段显示勾选入口。
