# 双语和历史数据库兼容说明

## 中英文切换

软件通过顶部「语言 / Language」菜单切换简体中文和 English，立即重建界面并恢复筛选、搜索词、选中设备及分隔条比例。语言偏好保存在本地 SQLite 的 `settings` 表中。

设备状态等数据库值继续使用原历史格式（例如「在用」「维修」），英文只在显示时翻译。CSV/XLSX 可使用中英文列名导入，业务状态会转换成数据库原格式。

## 固定清单（1.3.0 起）

清单统一采用固定 14 列，并在新增/编辑表单中显示其中的可编辑项。以前版本保存在 `settings` 表中的 `ui_visible_fields_v2`、`ui_form_fields`、`ui_list_fields` 不再控制界面，但这些旧键没有从数据库删除，以便兼容历史文件。

「公司」等历史字段仍然保存在数据库中，用户可通过「默认公司与提醒」设置新增记录的公司；完整 CSV/Excel 导出继续包含历史业务列。

## 数据迁移

启动时会检测旧版设备表缺失的列并补齐。它不会自动删除设备记录或附件。请只在备份的数据库副本上验证升级，再切换真实工作数据。原编辑密码仍受保护。

## Windows DPI

软件启动时尽量启用 Windows Per-Monitor V2 DPI 感知，并依照初始屏幕设置字体和控件缩放。运行中跨不同缩放比例的屏幕拖动窗口仍可能需要重新打开程序；这部分尚须 Windows 实机检查。
