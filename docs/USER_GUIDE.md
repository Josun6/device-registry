# Device Registry 1.3.0 使用指南

## 界面

顶部「语言 / Language」可切换中文 / English。搜索、公司、办公地点、产权人、存放位置、状态，以及查询和重置都保持在同一行；窗口较窄时通过搜索栏下方的横向滚动条浏览。

**资产清单固定 14 列**：设备名称、设备编码、型号、办公地点、产权人、存放位置、状态、数量、单位、单价(元)、购买日期、保修期(月)、当前净值(元)、备注。上一版的「显示字段」设置已移除。旧设备中的公司、状态日期等字段仍保留在数据库中。

表头使用 10pt 字体，根据窗口与内容计算列宽；总宽超出窗口时通过**清单底部横向滚动条**查看，不强行把标题挤小。

## 添加或修改设备

1. 点击「新增设备」，填写设备名称和设备编码（必填）。
2. 型号、办公地点、产权人、存放位置、状态、数量、单位、单价、购买日期、保修期、备注均为固定录入项；界面下方还可选择图片。
3. 购买日期默认当天，数量默认 1，状态默认「在用」。
4. 保存后可以在右侧「单据」添加发票、采购合同及其他附件。
5. 当前净值由购买日期、单价、折旧年限和残值率计算，不能手动输入。

从旧库修改设备时，公司等非显示字段仍会保留。原状态未改变时，状态日期也保持原值；修改状态后状态日期更新为当天。

## 默认公司和提醒

点击「设置 → 默认公司与提醒」可设置默认所属公司，或开关保修到期/维修超期提醒。如果历史设备只有一个公司而未设置默认公司，新设备会沿用这个公司。这个设置**不允许改变表格列的显示**。

## 调整左右区域

鼠标移到资产清单与右侧设备详情之间的蓝色竖向把手上，按住左键左右拖动。松开后会保存位置。重新启动或调整窗口尺寸时，程序会恢复相近比例；两侧都有最小宽度，避免被完全压没。

## 编辑密码保护

新建数据库默认可直接编辑。需要限制修改时，在「设置 → 编辑保护设置」主动启用密码；以后可以锁定与解锁。已有密码的旧库保持只读，直到输入旧密码。关闭密码保护必须验证当前密码。密码不加密 SQLite、图片、附件或备份。

## 导入、导出与备份

- 导出表单：支持 CSV，安装 `openpyxl` 后支持 XLSX。为保护迁移完整性，导出包含数据库的完整业务列，而不局限于主界面 14 列。
- 导入表单：支持旧版表头；已有编码会按编码匹配更新，导入文件中缺少的字段保留旧值。
- 导出备份：ZIP 包含数据库、图片与附件。
- 恢复备份：覆盖现有数据，恢复前保留 `devices.db.bak`。先用副本测试，不要恢复到唯一一份原始数据。

## Windows 测试注意

建议在 100%、125%、150%、175%、200% 缩放及不同窗口宽度下检查表头、滚动条、分隔条、子窗口图标与双语切换；最终 EXE 应在 Windows 10/11 实际运行验收。
